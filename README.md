# 🎸 Guide du Guitariste Débutant : Évitez les pièges, gagnez des années de pratique

> **Le condensé de 40 ans d'expérience pour ne pas abandonner la guitare après 3 mois.**

## 📋 Résumé du projet
Ce guide n'est pas une méthode de solfège académique. C'est un **"kit de survie"** écrit par un guitariste de terrain (40 ans de pratique, passage au Conservatoire à 50 ans) pour aider les débutants à naviguer dans la jungle du matériel et de l'apprentissage.

### 🚀 Points forts
- **Hardware :** Constituer son kit idéal pour moins de 50€.
- **Biologie :** Pourquoi vos doigts ne sont pas "trop gros" (optimisation neuronale).
- **Anti-Marketing :** Comment repérer les vendeurs de "lave-linge".
- **Agilité :** La règle des 80/20 pour jouer du Rock immédiatement.
